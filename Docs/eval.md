# Evaluation Strategy: Phase-wise Metrics & Testing

This document defines the evaluation criteria and success metrics for each development phase outlined in `implementation.md`. These checks ensure the Facts-Only FAQ Assistant meets quality, compliance, and performance standards before moving to the next phase.

---

## Phase 1: Project Setup & Scaffolding

**Objective:** Ensure the environment is properly configured to support the backend pipelines and frontend UI.

### Evaluation Criteria
- [ ] **Structure Validation:** All directories (`data/raw/`, `embeddings/`, `src/ingestion/`, etc.) exist and Python packages (`__init__.py`) are recognizable.
- [ ] **Dependency Check:** Running `pip install -r requirements.txt` completes without version conflicts (specifically for `langchain`, `chromadb`, `groq`, and `sentence-transformers`).
- [ ] **Environment Variables:** `python-dotenv` successfully loads the `GROQ_API_KEY` from the `.env` file without exposing it in the codebase.
- [ ] **Configuration Loads:** `config/settings.py` can be imported and yields the correct list of 5 Groww URLs and the BGE embedding model name.

---

## Phase 2: Data Ingestion Pipeline

**Objective:** Validate that the raw data from Groww is accurately scraped, chunked, and stored as BGE vector embeddings.

### Evaluation Criteria
- [ ] **Scraping Success Rate:** 5 out of 5 Groww URLs return a HTTP 200 status and yield non-empty text payloads.
- [ ] **Cleanliness Metric:** A random sample of 5 extracted text documents contains `< 1%` HTML boilerplate (tags, inline JS, navigation menus).
- [ ] **Chunking Integrity:** 
  - Chunks maintain the configured token size (~512 tokens).
  - 100% of generated chunks contain valid metadata dictionaries (`source_url`, `fund_name`, `last_updated`).
- [ ] **Vector DB Upsert:** 
  - Local ChromaDB initializes successfully in the `embeddings/` directory.
  - The total number of records in ChromaDB exactly matches the total number of chunks generated by LangChain.
- [ ] **Embedding Verification:** A test query using `sentence-transformers` (BGE model) against ChromaDB returns a valid distance score for the Top-1 result.

---

## Phase 3: RAG Query Engine & Refusal Logic

**Objective:** Ensure the system accurately retrieves facts, formats responses strictly, and blocks non-factual queries.

### Evaluation Criteria
- [ ] **Refusal Accuracy (Precision/Recall):**
  - **Advisory Test Set:** 10 out of 10 known advisory queries (e.g., "Should I invest?", "Is this a good fund?") are blocked.
  - **Factual Test Set:** 10 out of 10 factual queries (e.g., "What is the exit load?") pass through the gate.
- [ ] **Retrieval Hit Rate (Top-3):** For a test bank of 20 factual questions, the chunk containing the ground-truth answer appears in the Top-3 results at least 90% of the time.
- [ ] **LLM Generation Compliance:**
  - **Length:** 100% of test responses are 3 sentences or fewer.
  - **Citation:** 100% of test responses include exactly one `Source: <URL>` link.
  - **Footer:** 100% of test responses include `"Last updated from sources: <date>"`.
- [ ] **Hallucination / Fallback Check:** When asked a question explicitly missing from the corpus (e.g., "Who is the fund manager's wife?"), the LLM outputs exactly: *"I could not find this information in the available sources."*

---

## Phase 4: User Interface (Streamlit)

**Objective:** Verify the user experience is seamless, minimal, and correctly integrated with the Groq backend.

### Evaluation Criteria
- [ ] **Launch Success:** `streamlit run src/ui/app.py` boots successfully on `localhost:8501` with zero console errors.
- [ ] **UI Component Rendering:** 
  - The "Facts-only. No investment advice." disclaimer is highly visible.
  - The 3 default example questions are present and clickable.
- [ ] **End-to-End Latency:** 
  - A standard factual query processes through Retrieval -> Groq LLM -> UI display in **under 3.5 seconds**.
- [ ] **Markdown Formatting:** Links (citations) and bullet points generated by the LLM render correctly as clickable HTML in the Streamlit chat interface.
- [ ] **Stateless Behavior Verified:** Asking a follow-up question using a pronoun (e.g., "What is its expense ratio?") without specifying the fund name correctly prompts the bot to ask for clarification, proving no context leakage between turns.
